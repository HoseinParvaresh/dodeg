# ساخت APK بدون نصب Android Studio (ساخت ابری با GitHub)

GitHub روی سرورهای خودش پروژه را می‌سازد و APK را برایت آماده می‌کند. روی کامپیوتر خودت چیزی نصب نمی‌شود.

> ⚠️ این روش هم مثل کدهای Kotlin هنوز تست نشده؛ اگر خطا داد، متن خطای قرمز را برای من بفرست.
> اگر GitHub از اینترنت شما باز نمی‌شود یا حساب را محدود کرد، با VPN امتحان کن.

## مراحل
1. در `capacitor.config.json` مقدار `appId` را `ir.hparvaresh.dodge` بگذار.
2. در github.com حساب بساز (اگر نداری) و یک **repository جدید** بساز (ترجیحاً Private).
3. **محتوای همین zip** را آپلود کن: دکمه‌ی **Add file ← Upload files**، همه‌ی فایل‌ها و پوشه‌ها را بکش و رها کن، بعد **Commit changes**.
   - پوشه‌های `node_modules`، `android` و `www` را اگر قبلاً در کامپیوترت ساخته‌ای آپلود **نکن**.
   - پوشه‌ی `.github` باید آپلود شود. اگر نشد: **Add file ← Create new file**، اسم فایل را `.github/workflows/build-apk.yml` بنویس و محتوای فایل `native/cloud-build/build-apk.yml` را داخلش بچسبان.
4. به تب **Actions** برو. اگر پیام فعال‌سازی داد، تأییدش کن.
5. در سمت چپ **Build APK** را انتخاب کن ← **Run workflow** ← دوباره **Run workflow** (ورودی‌ها را خالی بگذار).
6. حدود ۱۰ تا ۲۰ دقیقه صبر کن تا کنار آن تیک سبز بیاید. روی اجرا کلیک کن، پایین صفحه در بخش **Artifacts** فایل `dodge-apk` را دانلود کن.
7. فایل zip را باز کن؛ داخلش `app-debug.apk` هست. آن را به گوشی بفرست (کابل یا تلگرام)، «نصب از منابع ناشناس» را اجازه بده و نصب کن.

## اگر ساخت قرمز شد
روی مرحله‌ی قرمز کلیک کن، چند خط آخر پیام خطا را کپی کن و برایم بفرست.

# ساخت APK امضاشده برای بازار و مایکت

> نسخه‌ی debug (بالا) فقط برای تست است. فروشگاه‌ها APK **امضاشده‌ی release** می‌خواهند.
> چون دیگر پرداخت درون‌برنامه‌ای نداریم، **یک APK برای هر دو فروشگاه** کافی است.

## الف) ساخت کلید امضا (فقط یک‌بار)
1. در GitHub: **Actions ← Create keystore ← Run workflow**.
2. بعد از تمام شدن، فایل‌های `dodge-keystore` را از بخش **Artifacts** دانلود و باز کن. (فقط ۱ روز می‌ماند.)
3. **هر دو فایل (`dodge-release.jks` و `keystore-secrets.txt`) را جای امن ذخیره کن** (مثلاً ایمیل به خودت یا فضای ابری).
   اگر این کلید گم شود دیگر نمی‌توانی آپدیت بدهی، و GitHub بعد از ذخیره‌ی Secret آن را نشان نمی‌دهد.
4. در repository: **Settings ← Secrets and variables ← Actions ← New repository secret** و دو Secret بساز:
   - اسم `KEYSTORE_PASSWORD` ← مقدار: رمزی که در `keystore-secrets.txt` جلوی `KEYSTORE_PASSWORD=` است
   - اسم `KEYSTORE_BASE64` ← مقدار: خط طولانی زیر عبارت `KEYSTORE_BASE64` همان فایل (کل خط)

> repository باید **Private** باشد.

## ب) ساخت APK نهایی
1. **Actions ← Build release APK ← Run workflow**.
2. `version_code` = ‏1 و `version_name` = ‏1.0 (بقیه‌ی ورودی‌ها فعلاً خالی).
3. بعد از تیک سبز، از **Artifacts** فایل `dodge-release-apk` را دانلود کن؛ داخلش `app-release.apk` است.
4. همین یک فایل را هم در پنل بازار و هم در پنل مایکت آپلود کن.

## پ) آپدیت‌های بعدی
دوباره **Build release APK** را اجرا کن و `version_code` را یکی بالاتر بگذار (2، 3، …).

## قبل از انتشار واقعی
- در `js/config.js` zone های تست تپسل را با zone های واقعی عوض کن و ورودی `tapsell_app_key` را با کلید واقعی تپسل پر کن.
- آیکن برنامه را عوض کن.

# آیکن و صفحه‌ی شروع برنامه

ساخت ابری هر بار پروژه‌ی اندروید را از نو می‌سازد، پس آیکن را در خود پروژه می‌گذاریم و workflow آن را خودکار در همه‌ی اندازه‌های اندروید می‌گذارد.

1. فایل `assets/icon.png` همان آیکن برنامه است. یک آیکن پیش‌فرض (دایره‌ی سفید و خط‌های قرمز بازی) گذاشته‌ام تا بدون هیچ کاری هم کار کند.
2. برای آیکن خودت، یک تصویر **PNG مربع ۱۰۲۴×۱۰۲۴** (حداقل ۵۱۲) با پس‌زمینه‌ی تمام‌رنگ بساز و جای `assets/icon.png` در repository بگذار.
   - هنر اصلی را وسط و با حاشیه‌ی کافی بکش؛ اندروید آیکن را به شکل دایره یا گرد می‌برد و گوشه‌ها بریده می‌شوند. ناحیه‌ی امن حدود ۷۰٪ وسط تصویر است.
   - رنگ پس‌زمینه‌ی آیکن‌های گرد از گوشه‌ی بالا-چپ تصویر خوانده می‌شود، پس پس‌زمینه باید یکدست باشد.
   - اگر پس‌زمینه‌ی تو یکدست نیست، یک فایل `assets/icon-foreground.png` (فقط هنر، با پس‌زمینه‌ی شفاف، ۱۰۲۴×۱۰۲۴) هم بگذار و رنگ پس‌زمینه را در workflow با متغیر `ICON_BG` (مثل `#121316`) بده.
3. بعد از جایگزینی، **Build APK** یا **Build release APK** را دوباره اجرا کن.

همین مرحله صفحه‌ی شروع پیش‌فرض Capacitor (لوگوی Capacitor) را هم با پس‌زمینه‌ی تیره‌ی بازی و آیکن خودت عوض می‌کند. اسم برنامه‌ای که زیر آیکن نشان داده می‌شود `appName` در `capacitor.config.json` است.
